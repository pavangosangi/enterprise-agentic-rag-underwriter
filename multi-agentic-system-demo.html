The Business Case

Accelerating Underwriting safely in a highly regulated environment.

The Challenge

  • Manual Bottlenecks: Underwriters spend excessive time searching complex, multi-layered Property&Causality PDF manuals to find base rates and policy guidelines.
  • The Generative AI Risk: Standard RAG or naive LLM implementations are too risky for insurance. They hallucinate actuarial calculations and can be tricked via prompt injection into providing non-compliant policy advice.
  • Data Privacy Strategy: Balancing the need for powerful LLM reasoning with strict data governance regarding proprietary underwriting rules.

The Objective

Engineer a hybrid conversational agent that acts as a secure, deterministic assistant. It leverages local models for secure, zero-leakage routing and safety checks, while strategically utilizing cloud APIs for high-compute evaluation and reasoning tasks.

System Architecture

A multi-agent, deterministic state graph.

Architectural Highlights

  • Separation of Concerns: The workflow utilizes specialized nodes. A Supervisor routes requests, a Policy Researcher handles retrieval, and an Actuary Calculator performs exact math.
  • Mandatory Guardrails: Every query passes through a local Safety Guardrail node to validate the domain and intercept prompt injections before downstream processing.
  • Tiered AI Compute: A deliberate hybrid approach routing highly sensitive guardrail tasks to local containerized models, while offloading evaluation to scalable cloud APIs.

Tech Stack & Implementation

A hybrid ecosystem balancing privacy, capability, and observability.

Orchestration & Compute

  • LangGraph & FastAPI: Drives the deterministic state workflow and serves the backend bridging the Streamlit UI.
  • Ollama (Local Tier): Runs Llama 3.1 and Mistral locally for the Supervisor and Safety nodes, ensuring initial data boundaries are secure.
  • Google Gemini API (Cloud Tier): Powers the advanced ReAct reasoning agents and serves as the Judge LLM for evaluation pipelines.

Data & Retrieval

  • Qdrant: Local vector database handling hybrid search (BM25 sparse + nomic dense embeddings).
  • Unstructured API: Parses complex, unstructured P&C PDF manuals during the containerized ingestion pipeline.

Evaluation & Observability

  • DeepEval (EaaS): On-demand evaluation utilizing Gemini API to run custom metrics (ToolChaining, IdentityBoundary).
  • OpenTelemetry: Captures distributed traces written to a local traces.jsonl file, visualizing latency and internal state.

Infrastructure

  • Docker Compose: The core application components are containerized, allowing for predictable deployments and controlled cloud egress.

Future Roadmap

Transitioning to the Model Context Protocol (MCP) for enterprise scale.

Turn Retrieval into a Standalone Skill

By moving the Qdrant hybrid search tool out of the core LangGraph flow, we create a dedicated Data MCP Server. This elevates P&C policy retrieval from a local script into a universal enterprise skill that any authorized agent can use.

Package Eval-as-a-Service

Instead of keeping the DeepEval metrics tied to our specific FastAPI backend, we package them into an independent Eval MCP Server. This allows any future AI project in the company to send their chat logs to our centralized Gemini judge to be scored on relevancy and precision.

Safe and Easy Code Modifications

Because these skills live inside their own isolated Docker components, updating them is incredibly easy and safe. If a developer needs to tweak the retrieval chunking logic or add a new custom graph metric, they only touch that specific container. There is zero risk of breaking the main orchestrator or other agents.

Zero-Friction Tool Discovery

(No API Contracts): With MCP, a calling application or developer no longer has to read complex API documentation to figure out how to integrate a service. The MCP server automatically broadcasts its JSON schema and capabilities. The AI model instantly discovers the tool, understands what parameters it needs, and knows exactly how to invoke it on the fly.
